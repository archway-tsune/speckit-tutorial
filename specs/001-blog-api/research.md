# 技術調査結果: ブログ記事管理API

**ブランチ**: `001-blog-api` | **作成日**: 2026-01-28

## 概要

本ドキュメントでは、ブログ記事管理APIの実装に必要な技術選定の根拠と調査結果を記録する。

## 技術スタック選定

### ランタイム: Node.js (LTS)

**選定理由**:
- プロジェクト憲章で指定済み
- 非同期I/Oによる高いスループット
- npm エコシステムの豊富なパッケージ
- フロントエンド開発者との技術スタック統一が容易

**バージョン**: 20.x LTS

### フレームワーク: Express.js

**選定理由**:
- プロジェクト憲章で指定済み
- 軽量で柔軟なミドルウェア構成
- 学習コストが低い
- 豊富なドキュメントとコミュニティ

**代替候補検討**:
| フレームワーク | 利点 | 不採用理由 |
|---------------|------|-----------|
| Fastify | 高パフォーマンス | 憲章でExpress指定 |
| Koa | よりモダンなAPI | 憲章でExpress指定 |
| NestJS | 構造化されたアーキテクチャ | 本プロジェクトには過剰 |

### データベース

#### 開発環境: SQLite (better-sqlite3)

**選定理由**:
- プロジェクト憲章で指定済み
- セットアップ不要（ファイルベース）
- テスト環境での高速実行
- 本番PostgreSQLとの互換性を考慮したSQL使用

**ライブラリ**: `better-sqlite3`
- 同期APIで直感的
- ネイティブバインディングで高速

#### 本番環境: PostgreSQL

**選定理由**:
- プロジェクト憲章で指定済み
- スケーラビリティ
- 堅牢なトランザクション
- 豊富な機能（JSON、全文検索等）

### 認証: JWT (jsonwebtoken)

**選定理由**:
- 仕様書でJWT認証を要求
- ステートレス認証でスケーラブル
- 業界標準

**実装方針**:
- アクセストークン: 1時間有効、署名アルゴリズムHS256
- リフレッシュトークン: 7日間有効、データベースで管理
- トークンペイロード: `{ userId, email, iat, exp }`

### パスワードハッシュ: bcrypt

**選定理由**:
- 仕様書で指定済み
- 業界標準のセキュアなハッシュアルゴリズム
- ソルト自動生成
- コスト係数による計算時間調整

**設定**:
- コスト係数（saltRounds）: 10（推奨値）

### UUID生成: uuid (v4)

**選定理由**:
- データベースのプライマリキーとして使用
- 衝突可能性が極めて低い
- 予測困難でセキュリティ向上

### テスト: Jest

**選定理由**:
- プロジェクト憲章で指定済み
- オールインワンテストフレームワーク
- モック機能が充実
- カバレッジレポート内蔵

**補助ライブラリ**:
- `supertest`: HTTPリクエストテスト用

## パフォーマンス考慮事項

### データベースインデックス

効率的なクエリのため、以下のインデックスを設定:

- `users.email`: ログイン時の検索
- `posts.author_id`: ユーザーの記事取得
- `posts.status`: ステータスフィルタリング
- `posts.created_at`: ソート
- `refresh_tokens.token`: トークン検証
- `refresh_tokens.user_id`: ログアウト時の削除

### ページネーション

- OFFSET/LIMIT方式を採用（シンプルさ重視）
- 大規模データセットの場合はカーソルベースへの移行を検討

### 接続プーリング

- 本番PostgreSQL環境では接続プーリングを使用
- 推奨: pg-pool または PgBouncer

## 移行戦略

### SQLite → PostgreSQL

1. **データ型マッピング**
   - TEXT (UUID) → UUID
   - TEXT (日時) → TIMESTAMPTZ

2. **マイグレーションスクリプト**
   - 環境変数でDB種別を切り替え
   - 抽象化レイヤーでSQL差異を吸収

3. **テスト戦略**
   - ユニットテスト: モック使用
   - 統合テスト: SQLiteで実行
   - E2Eテスト: PostgreSQLで実行（オプション）
